本文介绍桌面版的首次使用流程：启动应用、接入流量、解密 HTTPS、查看会话，以及改写请求。各步骤附有相关文档，可按需了解更多。

## 1. 启动

<Screenshot src="workbench-overview.png" alt="Sniffy 桌面版主窗口：顶部代理栏、左侧图标栏、中间流量列表" caption="桌面版主界面" />

安装完成后（见[安装](/docs/install/)）直接启动应用。窗口顶部是代理栏，它说明了当前状态：

- **监听中 `:8080`** —— 代理已经在本机监听；端口可在「设置 - 代理」中修改，改动需要重启应用。
- **系统代理已开 / 未开** —— 是否已经把本机的 HTTP/HTTPS 代理指向 Sniffy。
- **暂停 / 继续** —— 暂停只停止记录新流量，端口仍然监听，已有连接不受影响。

左侧图标栏是六个主界面：流量、重写规则、断点、插件、证书、设置。

## 2. 接入流量

在代理栏点击**开启系统代理**，Sniffy 会将系统的 HTTP/HTTPS 代理设为自己的监听地址。遵循系统代理设置的应用会通过 Sniffy 发送请求。

如果只想让某个应用走 Sniffy，或者系统代理对目标程序不生效，就手动把该程序的 HTTP / HTTPS 代理设为 `127.0.0.1:8080`。抓手机或另一台机器的流量时填写本机的内网地址，代理栏的网络菜单会列出可用的网卡地址。

其余方式（SOCKS5、上游代理、代理认证、限速）见[接入流量](/docs/capture/)。

访问一个 `http://` 页面，确认流量列表中出现记录。查看 HTTPS 请求与响应还需要让客户端信任根证书，步骤如下。

## 3. 信任根证书

<Screenshot src="certs-install.png" alt="证书页面，显示当前平台的安装引导与「安装到本机」按钮" caption="证书页面的安装引导" />

HTTPS 流量默认加密，要看到内容就得让客户端信任 Sniffy 的根证书。打开左侧**证书**页面：

- **macOS / Windows**：点击「安装到本机」，Sniffy 会调用系统工具写入信任库并弹出授权对话框。也可以下载 `.crt` 后按页面上的步骤手动安装。
- **Linux**：点击安装，通过 `pkexec` 授权后写入系统信任库，并尝试同步当前用户的浏览器 NSS 证书库。浏览器仍提示证书错误时，可手动导入。
- **iOS / Android**：切到对应平台的引导，按步骤配置 Wi-Fi 代理并安装证书。

装完后重启浏览器，再次访问 HTTPS 站点，流量列表里就会出现解密后的请求与响应。

证书的完整说明、解密范围、以及证书固定导致的失败，见 [HTTPS 解密与根证书](/docs/https/)。

## 4. 查看第一条会话

<Screenshot src="workbench-detail-panel.png" alt="详情面板上下两栏展示一条请求与响应，页签为总览 / 参数 / 头部 / 正文 / 原始" caption="会话详情面板" />

流量列表按时间倒序记录每条请求，列出方法、URL、状态码、耗时、大小、发起进程与客户端 IP。

- 顶部的搜索框（`Ctrl+F`）按 URL、Host、方法、状态码、进程名过滤。
- 旁边的筛选可以只看错误或图片。
- **跟随最新**打开时列表会自动滚到底部；手动向上滚动会自动关闭它。

点击任意一行打开详情面板，上下两栏分别是请求与响应：

| 页签   | 内容                                                       |
| ------ | ---------------------------------------------------------- |
| 总览   | 方法、协议、状态码、耗时、大小、客户端 IP、发起进程        |
| 参数   | 查询参数与表单参数                                         |
| 请求头 / 响应头 | 头部键值表，点击即可复制                          |
| 请求体 / 响应体 | 按内容类型渲染：JSON 树、文本、Hex，图片与音视频可直接预览 |
| 原始   | 未经整理的报文文本                                         |

在详情里按 `Ctrl+F` 可以在当前会话内查找，作用范围能在请求、响应、内容之间切换。

右键一行还能复制 URL、复制为 cURL、标记颜色、标记已读未读、删除或重发。完整导览见[工作台导览](/docs/workbench/)。

## 5. 改一次请求

Sniffy 提供四种改写方式，可以根据是否需要自动执行、是否需要编写逻辑来选择：

| 方式         | 何时用                                             | 文档                                 |
| ------------ | -------------------------------------------------- | ------------------------------------ |
| 请求构造器   | 编辑并重发已有请求，或构造新请求                  | [请求构造器](/docs/compose/)         |
| 重写规则     | 按固定条件自动替换，无需编写代码                  | [重写规则](/docs/rules/)             |
| 断点         | 暂停指定流量，手动检查和修改后放行                | [断点](/docs/breakpoints/)           |
| JavaScript 插件 | 编写条件分支、计算签名或跨请求保存状态         | [JavaScript 插件](/docs/plugins/)    |

在流量列表里右键点击一条请求，选择**编辑后重发**。构造器会载入请求的方法、URL、头部和可编辑的请求体。修改后点击发送，新会话会出现在流量列表中，并标记为「重发」。

规则和插件可以自动改写流量。例如，下面的插件会匹配 `/api/profile`，直接返回指定的 Mock 响应：

```js
function onRequest(flow) {
  if (flow.path !== "/api/profile") return;

  mock({
    status: 200,
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ name: "Sniffy", plan: "pro" }),
  });
}
```

在**插件**页面新建插件、粘贴脚本、保存并启用即可。
