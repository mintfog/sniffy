Sniffy 是开源、跨平台的抓包与调试工具。它通过本机代理记录 HTTP、HTTPS 与 WebSocket 流量，并支持在转发过程中查看和改写请求与响应。

Sniffy 提供**桌面版**和**无界面版**（headless）：桌面版通过工作台操作，无界面版通过 REST 与 WebSocket 接口管理。两者共用抓包引擎、规则与插件系统。
