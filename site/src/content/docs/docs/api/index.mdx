无界面版通过独立的管理端口提供 REST 接口与 WebSocket 事件流，用于查询会话、修改配置、管理规则与插件、处理断点，以及导入导出证书。

这些网络接口由无界面版提供。桌面版通过进程内接口调用共享服务，不启动管理 API 服务。

## 基础地址

| 项目       | 默认值                    | 修改方式                                    |
| ---------- | ------------------------- | ------------------------------------------- |
| 协议       | `http`                    | `-api-tls-cert` / `-api-tls-key` 启用 `https` |
| 地址       | `127.0.0.1`               | `-api-addr`                                 |
| 端口       | `8888`                    | `-api-port`                                 |
| 事件流入口 | `/api/ws`                 | 随上面三项变化                              |

绑定非回环地址时必须启用 TLS，否则默认拒绝启动。详见[认证与安全](/docs/api/auth/)。

## 快速开始

```bash
# 1. 启动无界面版
./sniffy

# 2. 取 token(启动日志里也会打印它的路径)
export SNIFFY_API_TOKEN="$(cat ~/.config/sniffy/api_token)"
export SNIFFY_API=http://127.0.0.1:8888

# 3. 确认服务在跑
curl -s $SNIFFY_API/api/status \
  -H "Authorization: Bearer $SNIFFY_API_TOKEN"

# 4. 让一条流量经过代理
http_proxy=http://127.0.0.1:8080 curl -s http://example.com > /dev/null

# 5. 把它读回来
curl -s "$SNIFFY_API/api/sessions?pageSize=1" \
  -H "Authorization: Bearer $SNIFFY_API_TOKEN"
```

第 3 步返回 `{"data":{"status":"running",...},"success":true}` 就说明接口通了。返回 401 见[认证与安全](/docs/api/auth/)。

## 端点索引

全部端点一览，按主题分组。每个端点只放行这里列出的方法，其余返回 405。

### 状态与配置

| 端点                      | 方法              | 说明                     |
| ------------------------- | ----------------- | ------------------------ |
| `/api/status`             | GET, HEAD         | 运行状态、版本与运行时长 |
| `/api/statistics`         | GET, HEAD         | 累计与实时指标           |
| `/api/config`             | GET, HEAD         | 读取配置视图             |
| `/api/config`             | PUT, POST         | 补丁式修改配置           |
| `/api/recording/start`    | POST              | 开始记录                 |
| `/api/recording/stop`     | POST              | 停止记录                 |
| `/api/recording/status`   | GET, HEAD         | 当前是否在记录           |

### 会话

| 端点                             | 方法       | 说明                     |
| -------------------------------- | ---------- | ------------------------ |
| `/api/sessions`                  | GET, HEAD  | 分页列出 HTTP 会话       |
| `/api/sessions/clear`            | POST       | 清空全部会话             |
| `/api/sessions/{id}`             | GET, HEAD  | 读取单条会话             |
| `/api/sessions/{id}`             | DELETE     | 删除单条会话             |
| `/api/sessions/{id}/body`        | GET, HEAD  | 正文字节，base64 + MIME  |
| `/api/sessions/{id}/body/raw`    | GET, HEAD  | 正文字节流，支持 Range   |
| `/api/sessions/{id}/compose`     | GET, HEAD  | 构造器预填快照           |
| `/api/websocket-sessions`        | GET, HEAD  | 分页列出 WebSocket 会话  |
| `/api/websocket-sessions/{id}`   | GET, HEAD  | 单条 WebSocket 会话      |
| `/api/stream-sessions`           | GET, HEAD  | 分页列出流式会话         |
| `/api/stream-sessions/{id}`      | GET, HEAD  | 单条流式会话             |
| `/api/export`                    | POST       | 按条件导出会话数组       |

## 稳定性

接口跟随应用版本演进，目前没有独立的 API 版本号。`/api/status` 返回的 `version` 是应用版本，可用来在脚本里做兼容判断。

Sniffy 仍处于 beta 阶段。升级前请查看 [Release 说明](https://github.com/mintfog/sniffy/releases)，并验证调用方依赖的字段与行为。
