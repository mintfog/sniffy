工作台是桌面版的主界面。左侧图标栏在六个页面之间切换：**流量**、**重写规则**、**断点**、**插件**、**证书**、**设置**。本文讲流量页面，其余各自有独立文档。

## 代理栏

<Screenshot src="proxy-bar.png" alt="代理栏：监听端口、系统代理开关、暂停按钮与网络地址菜单" caption="窗口顶部的代理栏" />

窗口顶部固定显示代理状态：

- **监听中 `:8080`** —— 当前监听端口。网络菜单列出本机可用的局域网地址，供手机或其他设备连接。
- **系统代理已开 / 未开** —— 点击切换，见[接入流量](/docs/capture/#系统代理)。
- **暂停 / 继续** —— 停止或恢复新流量记录，代理继续监听和转发。
- **清空流量** —— 丢弃已记录的全部会话。
- 流量在断点处暂停时，代理栏会显示等待处理的请求数量。

## 流量列表

<Screenshot src="workbench-traffic-list.png" alt="流量列表，含方法、URL、状态、耗时、大小、进程等列" caption="流量列表" />

每条请求一行，按时间倒序排列。默认列：

| 列       | 说明                                              |
| -------- | ------------------------------------------------- |
| 方法     | GET / POST / …                                    |
| URL      | 完整地址，窄屏下优先显示 host 与 path             |
| 状态     | 响应状态码；进行中与出错各有独立样式              |
| 耗时     | 从请求写出到响应读完                              |
| 大小     | 响应体字节数                                      |
| 进程     | 发起请求的本机进程名与图标（能识别时）            |
| 客户端   | 客户端 IP                                         |
| 时间     | 请求开始时刻                                      |

### 搜索与筛选

顶部搜索框（`Ctrl+F` / `Cmd+F`）按 URL、Host、方法、状态码、进程名过滤，输入即时生效。旁边的快捷筛选可以只看**错误**或**图片**。

**跟随最新**打开时列表自动滚到底部；手动向上滚动会自动关闭，点击「最新」按钮可以跳回。

### 选择与批量操作

单击选中一行，`Ctrl/Cmd` 与 `Shift` 可多选，`Ctrl/Cmd+A` 全选。状态栏会显示已选条数。

右键菜单（对单条或整个选区生效）：

- **复制** —— URL、路径、请求头、请求体、响应头、响应体，或整条 cURL 命令
- **重发** —— 原样再发一次
- **编辑后重发** —— 送进[请求构造器](/docs/compose/)，改完再发
- **标记** —— 使用五种颜色高亮关键请求
- **标记已阅 / 未读**
- **删除** / **清空全部**

## 详情面板

<Screenshot src="workbench-detail-panel.png" alt="详情面板上下两栏展示一条请求与响应" caption="会话详情面板" />

点击一行在右侧打开详情，上下两栏分别是请求与响应，中间可拖动调整高度。

### 请求侧

| 页签   | 内容                                                       |
| ------ | ---------------------------------------------------------- |
| 总览   | 方法、协议、状态码、耗时、大小、开始时间、客户端 IP、发起进程 |
| 参数   | 查询参数与表单参数，分组展示                               |
| 请求头 | 头部键值表，点击键或值即可复制                             |
| 请求体 | 按内容类型渲染                                             |
| 原始   | 未经整理的报文文本                                         |

请求侧还有一个**复制为 cURL**按钮，把这条请求变成可以直接粘进终端的命令。

### 响应侧

页签为响应头、响应体、原始，另有 Cookie（`Set-Cookie`）分组。**保存响应体**把正文原样写到文件。

### 正文查看器

<Screenshot src="workbench-body-viewer.png" alt="正文查看器展示 JSON 树，右上角可切换到原文与 Hex" caption="正文查看器的 JSON 树" />

正文按内容类型自动选择呈现方式：

- **JSON** —— 可折叠的树，也可切到原文
- **文本 / HTML / XML** —— 带语法着色的文本
- **图片** —— 直接预览，可在「适应」与「原始尺寸」之间切换，可另存
- **音视频** —— 内嵌播放器，内容从缓存区的落盘副本流式读取
- **二进制** —— Hex 视图

大响应体使用透传处理时，详情页按需从缓存文件读取正文。206 分片响应仅包含文件的一部分，播放器会显示提示。

### 在详情内查找

详情面板获得焦点后按 `Ctrl+F` 打开查找条，作用范围可以在**请求**、**响应**、**内容**、**消息**之间切换。`Enter` / `Shift+Enter` 在结果间跳转。

## WebSocket 会话

<Screenshot src="workbench-ws-session.png" alt="WebSocket 会话的消息流，每帧标明方向、类型、大小与时刻" caption="WebSocket 消息流" />

WebSocket 的握手像普通请求一样出现在列表里，点开后详情面板是消息流：每一帧标明方向（发送 / 接收）、类型（文本 / 二进制）、大小与时刻，点击单条查看内容。二进制帧以 Hex 呈现。

超大帧只保留开头一段并标为「已截断」，显示的大小仍然是真实长度。

## 流式会话

SSE、gRPC 与分块流的消息会在到达时追加到详情面板。此类响应按消息处理，插件在 `onResponse` 中只能访问头部；逐条改写请使用 `onStreamMessage`，见 [JavaScript 插件](/docs/plugins/)。

## 导出

- **导出 HAR**（`Ctrl/Cmd+E`）—— 标准 HAR 1.2，可以导入 Chrome DevTools、Charles 等工具。
- **导出 JSON** —— Sniffy 自己的会话结构，字段与管理 API 返回的一致。

两者都导出**当前筛选后**的列表，而不是全部会话。headless 下经 `POST /api/export` 导出，支持按 ID、方法、Host、状态码、时间范围过滤，见[管理 API 参考](/docs/api/export/)。

## 工具箱

<Screenshot src="workbench-toolbox.png" alt="工具箱里的编码、解码、摘要与生成四组工具" caption="工具箱" />

菜单栏的「工具」提供以下离线工具：

| 分组     | 工具                                   |
| -------- | -------------------------------------- |
| 编码     | Base64 编码、URL 编码                  |
| 解码     | Base64 解码、URL 解码、JWT 解析        |
| 消息摘要 | MD5、SHA-1、SHA-256                    |
| 生成     | UUID、时间戳、二维码                   |

## 快捷键

| 快捷键                | 作用                       |
| --------------------- | -------------------------- |
| `Ctrl/Cmd+F`          | 聚焦搜索框                 |
| `Ctrl/Cmd+R`          | 暂停 / 继续捕获            |
| `Ctrl/Cmd+E`          | 导出 HAR                   |
| `Ctrl/Cmd+N`          | 打开空白请求构造器窗口     |
| `Ctrl/Cmd+A`          | 全选                       |
| `Ctrl/Cmd+Delete`     | 清空流量                   |
| `Ctrl/Cmd+Shift+C`    | 将焦点行复制为 cURL       |
| `Ctrl/Cmd+J`          | 切换深色 / 亮色主题        |
| `Delete` / `Backspace`| 删除选中                   |
| `R`                   | 重发选中                   |
| `Shift+R`             | 编辑后重发（打开构造器）   |
| `↑` / `↓`             | 在列表中移动焦点           |
| `Alt+K` / `Alt+B` / `Alt+P` | 跳到规则 / 断点 / 插件 |
| `Alt+1`…`Alt+5`       | 给焦点行打颜色标记         |
| `Alt+0`               | 清除颜色标记               |
| `Esc`                 | 关闭菜单 / 取消选择        |

## 外观

「设置 - 外观」可调整主题（深色 / 亮色）、强调色和字号。**紧凑模式**会减小流量列表行高，以显示更多会话。
