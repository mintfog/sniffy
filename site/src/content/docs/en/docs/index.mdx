Sniffy is an open-source, cross-platform tool for capturing and debugging network traffic. Its local proxy records HTTP, HTTPS, and WebSocket traffic and lets you inspect and rewrite requests and responses as they pass through.

Sniffy is available as a **desktop app** with a graphical workbench and a **headless service** managed through REST and WebSocket APIs. Both share the same capture engine, rules, and plugin system.
