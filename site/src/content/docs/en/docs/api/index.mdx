The headless service exposes REST endpoints and a WebSocket event stream on a separate management port. Use them to query sessions, update configuration, manage rules and plugins, resolve breakpoints, and import or export certificates.

These network APIs are provided by the headless service. The desktop app calls shared services through an in-process interface and does not start a management API server.

## Base URL

| Item             | Default        | How to change it                                |
| ---------------- | -------------- | ----------------------------------------------- |
| Scheme           | `http`         | `-api-tls-cert` / `-api-tls-key` switch to `https` |
| Address          | `127.0.0.1`    | `-api-addr`                                     |
| Port             | `8888`         | `-api-port`                                     |
| Event stream     | `/api/ws`      | follows the three above                         |

Binding a non-loopback address requires TLS, or startup is refused. See [Authentication and security](/en/docs/api/auth/).

## Quick start

```bash
# 1. Start the headless service
./sniffy

# 2. Get the token (its path is printed in the startup log too)
export SNIFFY_API_TOKEN="$(cat ~/.config/sniffy/api_token)"
export SNIFFY_API=http://127.0.0.1:8888

# 3. Confirm the service is up
curl -s $SNIFFY_API/api/status \
  -H "Authorization: Bearer $SNIFFY_API_TOKEN"

# 4. Send one request through the proxy
http_proxy=http://127.0.0.1:8080 curl -s http://example.com > /dev/null

# 5. Read it back
curl -s "$SNIFFY_API/api/sessions?pageSize=1" \
  -H "Authorization: Bearer $SNIFFY_API_TOKEN"
```

Step 3 returning `{"data":{"status":"running",...},"success":true}` means the interface works. A 401 is covered in [Authentication and security](/en/docs/api/auth/).

## Endpoint index

Every endpoint, grouped by topic. Each one permits only the methods listed here; anything else returns 405.

### Status and configuration

| Endpoint                  | Methods    | Purpose                              |
| ------------------------- | ---------- | ------------------------------------ |
| `/api/status`             | GET, HEAD  | Running state, version, uptime       |
| `/api/statistics`         | GET, HEAD  | Cumulative and live metrics          |
| `/api/config`             | GET, HEAD  | Read the configuration view          |
| `/api/config`             | PUT, POST  | Patch the configuration              |
| `/api/recording/start`    | POST       | Start recording                      |
| `/api/recording/stop`     | POST       | Stop recording                       |
| `/api/recording/status`   | GET, HEAD  | Whether recording is on              |

### Sessions

| Endpoint                          | Methods    | Purpose                          |
| --------------------------------- | ---------- | -------------------------------- |
| `/api/sessions`                   | GET, HEAD  | Paginated HTTP sessions          |
| `/api/sessions/clear`             | POST       | Discard every session            |
| `/api/sessions/{id}`              | GET, HEAD  | Read one session                 |
| `/api/sessions/{id}`              | DELETE     | Delete one session               |
| `/api/sessions/{id}/body`         | GET, HEAD  | Body bytes as base64 + MIME      |
| `/api/sessions/{id}/body/raw`     | GET, HEAD  | Body byte stream, Range support  |
| `/api/sessions/{id}/compose`      | GET, HEAD  | Composer pre-fill snapshot       |
| `/api/websocket-sessions`         | GET, HEAD  | Paginated WebSocket sessions     |
| `/api/websocket-sessions/{id}`    | GET, HEAD  | One WebSocket session            |
| `/api/stream-sessions`            | GET, HEAD  | Paginated streaming sessions     |
| `/api/stream-sessions/{id}`       | GET, HEAD  | One streaming session            |
| `/api/export`                     | POST       | Filtered session export          |

### Request composer

| Endpoint                          | Methods | Purpose                          |
| --------------------------------- | ------- | -------------------------------- |
| `/api/compose`                    | POST    | Send one request                 |
| `/api/compose/{id}/stop`          | POST    | End a composer-started stream    |
| `/api/compose/ws`                 | POST    | Open an outbound WebSocket       |
| `/api/compose/ws/{id}/send`       | POST    | Send a frame                     |
| `/api/compose/ws/{id}/close`      | POST    | Close the connection             |

### Rules, plugins, breakpoints

| Endpoint                                | Methods                 | Purpose                       |
| --------------------------------------- | ----------------------- | ----------------------------- |
| `/api/intercept/rules`                  | GET, HEAD, POST         | List / create rules           |
| `/api/intercept/rules/{id}`             | GET, HEAD, PUT, DELETE  | Read / replace / delete       |
| `/api/intercept/rules/{id}/toggle`      | POST, PUT               | Toggle one rule               |
| `/api/plugins`                          | GET, HEAD, POST         | List / create plugins         |
| `/api/plugins/{id}`                     | DELETE                  | Delete a plugin               |
| `/api/plugins/{id}/enable`              | POST                    | Enable                        |
| `/api/plugins/{id}/disable`             | POST                    | Disable                       |
| `/api/plugins/{id}/manifest`            | POST, PUT               | Update the manifest           |
| `/api/plugins/{id}/source`              | GET, HEAD, PUT          | Read / write the script       |
| `/api/plugins/{id}/logs`                | POST                    | Clear plugin logs             |
| `/api/breakpoints`                      | GET, HEAD, POST         | Paused list / global switches |
| `/api/breakpoints/global`               | GET, HEAD, PUT, POST    | Global breakpoint switches    |
| `/api/breakpoints/rules`                | GET, HEAD, POST         | List / create URL rules       |
| `/api/breakpoints/rules/{id}`           | GET, HEAD, PUT, DELETE  | Read / update / delete        |
| `/api/breakpoints/rules/{id}/toggle`    | POST, PUT               | Toggle one breakpoint rule    |
| `/api/breakpoints/{id}/resume`          | POST                    | Release, optionally with edits |
| `/api/breakpoints/{id}/abort`           | POST                    | Abort                         |
| `/api/breakpoints/{id}/extend`          | POST                    | Extend the deadline           |
| `/api/breakpoints/resume-all`           | POST                    | Release everything            |

## Stability

The interface tracks the application version; there is no separate API version. The `version` returned by `/api/status` is the application version and can be used for compatibility checks in scripts.

Sniffy is still in beta. Before upgrading, review the [release notes](https://github.com/mintfog/sniffy/releases) and verify the fields and behavior your client relies on.
